# 六極柱 ECR 推進器｜工程研究工作區

> 研究規劃版本：2026-10-12。這裡是研究方法與工作計畫，不是已完成的實驗成果。

## 建議研究題目

**永磁式六極柱 ECR 氙氣推進器之工程實現、磁場驗證與穩定操作特性研究**

以陳國益《緊湊型六極柱 ECR 離子源研究及在等離子推進器之應用》為起點，保留既有腔體與雙環形磁鐵，建立可拆六極柱模組、磁場實測驗證、Xe 電漿密度及連續運轉的工程證據。

## 核心研究問題

1. 實際磁材、探頭定位與裝配公差下，COMSOL 能否重現關鍵磁場分布？
2. 同腔體、天線、Xe 流量與可比功率下，雙環與雙環＋六極柱的密度及操作穩定性有何差異？
3. 哪些功率–流量工況能在有效背景壓力、可解釋探針資料與熱限制內連續運作？

## 時程界線

研究內部目標為 11 個月；第 3–4 個月完成預口試。期中與期末交付必須另依正式決標日及計畫文件追蹤，不把學校預口試當成契約期中。排程示例沿用 2026-10-06，實際起算日尚須確認。

## 使用限制

原論文的 94% 是共振面幾何覆蓋率；95% 是由正向及反射微波功率計算的比例，不是整體推力效率。原文代表性能來自 Ar 2 sccm、100 W；不能直接當作 Xe 原型的性能。
